# 如何创造充满意义、金钱与影响力的生活（以人类能做到的最快速度）

<ArticleMeta />

[观看原文视频](https://open.spotify.com/embed/episode/1ud7ipZwgV6V7ZwcOowUAA?si=42a63203f2af44bf&utm_source=oembed)

如果要把我所有的进步归功于一件事——那就是*清晰度*。确切地说，就是理顺意识的能力。清晰度让专注变得自然无缝，而我们都知道在这个信息时代这有多么重要。

小时候，不到12岁那会儿，我不管去哪儿都会随身带着个笔记本。就是那种开学采购时会买的“大学横线本”。只不过这本不是用来上学的。这是我画奇形怪状的怪物、机器人以及我那年轻的大脑所能想象出的任何东西的地方。

这些画通常都是同一个形状。一种有躯干、手臂、腿和头的人形生物。有时我会把它们画得肌肉发达，有时画得瘦骨嶙峋像外星人，有时长着角，有时顶着光环。

长大后，我不再画画了，但还是把笔记本留在身边。我不再画想象中的人物，而是写下关于我想象中未来的场景。如果你愿意的话，可以称之为愿景板。一张我需要采取哪些步骤才能到达在那里的地图。我会把这些钉在我电脑上方的墙上。每当我觉得特别懒散时，我的愿景就会直勾勾地盯着我的脸——提醒我为什么在这里。

## 将梦想（或噩梦）变成现实

意识孕育意识。思想孕育思想。想法孕育想法。项目孕育项目……我还能一直列举下去。

重点是：如果你没有先在脑海中想象过，你就无法为自己创造出未来的现实。

反之亦然，只有当你先想象过（或经历过），你才会创造出消极的当前现实。

如果没有车轮、马车、四轮马车、电力和汽车在它之前出现，特斯拉——这家公司——就不会存在。

这引出了一个可能是我们作为一个物种正在经历的最大问题。当然，我们也是唯一经历这个问题的物种，因为我们是现存唯一拥有认知能力去经历它的物种。

我说的是心理时间，或者说线性时间的概念。那是个大问题。回忆熟悉的过去——那些你曾经亲身经历过的事情——并产生同样熟悉的想法。这些想法将你过去的经历拉到现在。你确确实实有了相同的感官体验。你*就是*过去的自己。

当你重复这些想法、情绪和经历时——你的大脑会通过神经网络将这些模式固化。习惯和日常规律就是这样形成的。当它们处于无意识状态时是很危险的。你依然是过去的那个自己。一遍又一遍地重温着同样的消极想法和感官体验。我们必须学会如何编程（内在），否则就会被编程（外在）。*创造，或者被创造。*

同样的事情也发生在未来。你基于过去的经验投射并担忧着可预测的未来。再一次，你在当下感受到了这些经验，这意味着在你整个无意识的生命中，你根本没有改变过。

这些情况都有一个特定的神经网络。一个是针对你老板造成的压力。一个是关于洗澡。一个是关于你回家后和配偶争吵。随着时间的推移，这些变得越来越无意识，也越来越具灾难性。

大多数人一醒来，就会因为他们被设定的程序，立刻把思维投射到一个充满压力的未来中。他们作为过去版本的自己醒来，经历着他们每天早晨都在经历的一模一样的消极感官体验。

解决这个问题的唯一方法就是潜入未知。思考新的想法。接触新的观念。将自己沉浸在有利于成长的环境中（也就是我提出的“战术性压力”的概念）。建立能通向积极潜在现实的项目。采取那些别人告诉你是“危险的”且你不熟悉的行动——因为说那些话的人本身并没有经历过这种“风险”。

![](/images/92b926856ff545233901.png)

超过90%的人群都是行走的矛盾体。他们处于自动驾驶状态，过着一条“安全”且“确定”的道路——但在我们这个不断变化的世界里，这其实蕴含着最大的风险和不确定性。

## 21世纪最伟大的技能

正如我们所了解的，大脑会制造很多问题。这是由于精神熵——大脑倾向于混乱和无序。如果你[懂得如何驾驭这些阶段](https://thedankoe.com/if-you-feel-lost-understand-these-3-phases-of-life/)，这并不算是坏事。它们能带来丰厚的回报。然而，解决的方案是*清晰度*。有序的意识。能够以一种真正赋予其生命的方式来组织信息的能力。从思想到物质。

![](/images/e99717a688af7b323b37.png)

没有人知道自己一生想做什么。也没有人把这看作一种祝福。不知道你想要什么，意味着你可以在无限潜力的未知中去创造你想要的东西。我们会在未来的信件中深入探讨量子领域背后的科学。你只需要知道，未知是一切潜力存在的地方。如果它是已知的，那潜力就已经被具象化了。你需要打破这个习惯：在已知、熟悉、可预测的生活中，作为那个已知、熟悉、可预测的自我活着。

![](/images/116aa8242741a7b52adc.png)

现在，请明白这是一个巨大的话题。上面金字塔里的每一项都值得专门写一封信。人们已经就这个金字塔的各个不同方面写了整本整本的书。见鬼，连我自己都在写一本关于它的书。我们不可能在一篇文章里就把这些全弄明白。我所有未来和以前的文章都包含了这些内容。

在这封信中，我们将重点探讨如何梳理意识，为我们自己创造一个积极的现实。以下是实现这一目标的步骤：

**1) 物质层面 VS 非物质层面的体验**

> “我不是发生在我身上的事情，我是我选择成为的人。”——卡尔·荣格 (Carl Jung)

不要从唯物主义的范式去解读这句话。要从一种非物质的、经验的视角去思考。你*就是*你选择成为的人。就是现在。就在这一刻。在非物质世界里，不存在需要跨越的鸿沟。

当你进入最佳体验状态，或者说是心流状态时，你正在获得你所渴望的感官体验。你不在乎什么豪车、大房子或者生活方式。*你在乎的是它带给你的感觉或体验。*

你现在就可以实现那种体验。

**非主流观点：**“弄假直到成真 (fake it til you make it)” 是极好的建议。

从物质角度来看，这让你看起来像个骗子。从非物质角度来看，根本不存在弄假。你已经成为了那个人。物质世界迟早会跟上。

**2) 创造一个无比清晰的愿景**

我们如何潜入未知？通过我们大脑的力量，将我们想要吸引并通过意图去努力实现的潜在现实可视化。

有趣的事实：“意图 (Intention)”一词来源于拉丁语 *intentionem*（主格 *intentio*），意为“伸展、拉紧、发力、努力；注意力”，它是动词 *intendere*（意为“将注意力转向”）的动作名词，字面意思是“伸展”。

当你带着意图去行动（这也是创造金字塔中的一个驱动力）时——*你正通过注意力向着某样事物伸展。*

很多人*贬低*“吸引力法则”，但你不妨这样想：通过持续且具体的可视化，你正在框定你的焦点。当你练习专注于你的愿景（而不是让你感到压力的老板）时，你就在开始解除大脑中无意识的思维模式设定。

再举个例子：如果你相信自己能在网上赚钱（因为你对自己的愿景很清晰），你就会开始注意到赚钱的机会。*就像当你看到一辆以前没见过的特定汽车时*——然后你会发现它无处不在。你正在主动敞开心扉，去关注那些未知的、新的事物，并把这些经历“吸引”到你的生活中。

[通过明确你想要的未来是什么样子](https://thedankoe.com/how-to-finally-stop-caring-what-other-people-think/)——你就可以开始接入那种能量。

能量？你是说氛围吗？这是什么意思？

你有没有过“期待”去度假，并在此刻就感到兴奋？这就是我的意思。环境蕴含能量。自然蕴含能量。万物皆有能量。特定能量的频率就是信息。我们的大脑处理并组织信息。别再用唯物主义范式来思考这一切了。

**3) 将你的愿景逆向推导为目标**

设定目标的目的不是为了专注于它们，而是为了提供更多的清晰度，并证明它是可以实现的。*如果你愿意，你可以把这些看作是微观愿景。* 它们在这里仅仅是为了提供可以接入的额外能量源，并且当你准备将愿景变成现实时，能够创建一个可执行的流程。

这里的一切都是可变的。这就是为什么这是一个如此庞大且难以攻克的话题。在这个只有懂得“创造金字塔”的1%的人才能享有成功的世界里，我试图去保证你能成功。

我的做法是根据你试图创造的规模，将其分解为3个目标。如果你正努力创造更好的生活，眼界要放宽点。写下一个10年目标、1年目标，以及月度目标。

现在，我们可以通过执行特定的流程，来完成这些任务、里程碑、检查点，或者是“微观愿景”。

**4) 开始测试一个流程**

把这整个阶段看作是一场实验。除非你对具体的部分进行测试，否则你不会知道什么能带来结果。科学家们也不会在第一次就拿出能产生结果的可复制流程。它可能需要几周、几个月或几年的时间。

![](/images/8549cc296d59b11fd6cd.png)

在这里，耐心、信念和臣服是必不可少的。你正在创造一个前人从未创造过的现实。如果你想回到那条“安稳的”、可预测的、传统的世俗生活道路，请便。如果不想，那就向失败敞开怀抱吧。

为了让你正在努力吸引和创造的现实具象化，每天你能执行哪些能拨动杠杆的行动，以实现你的月度、年度、十年期乃至一生的愿景？

如果这部分让你感到焦虑，你需要自我教育和练习来提升你的技能。如果这部分让你感到无聊，你需要增加挑战的难度。

![](/images/ba223387f0eeaac06708.png)

**5) 运用内在驱动力作为杠杆**

好奇心、激情、使命感、灵感和意图，都是你可以随时调用来提高工作质量的工具。

这些都会影响你大脑中的多巴胺和其他神经化学物质。当你[通过追求好奇心获得灵感](https://thedankoe.com/how-to-copy-your-way-to-success-instead-of-mediocrity/)时，你的工作会做得更好。当你有强烈的动力或使命感时，你的工作也会做得更好。这些都是你可以随时接入的能量源。

这些应该是内在的动机，而不是外在的。

**6) 控制并引导你的注意力**

![](/images/12f7bb8d24d3a9d76ee0.png)

这本身就值得写一篇完整的文章。现在，你需要明白的是，你可以从金字塔的任何一层汲取能量。这些都是释放创造力能量的选择。

注意力不仅付出能量，也接收能量。我们处理来自各种频率的信息，但前提是我们必须将注意力放在上面。

当你在无意间把注意力集中在负面能量上时——比如想象工作时与老板之间充满压力的场景——你就在接入那个能量源。这里存在着能量的交换，你会*感觉*到能量正在被浪费。

通过管理你的注意力，你释放出能量，从而将最大的努力投入到你的愿景中。

遇到疑惑时，把注意力拉回当下。扩展你的觉察力。打开你的专注力。去挖掘未知所蕴含的无限潜能和积极性。

你对未来愿景的一个方面是凭借一项创意技能赚取6位数。我们可以更具体一点，而且你也应该更具体，但让我们先把它拆解成目标：

## 变得多维度强悍

创造力金字塔不仅是为了给自己创造更好的生活。它可以应用于你个人和职业生活的各个维度。

![](/images/f0a2c26c9326df049b30.png)

*开启一个新项目？*

为它建立一个愿景，通过设定目标获得清晰度，减少采取行动的阻力，并保持专注。

*建立一段更好的关系呢？*

为你希望与另一半如何互动建立一个愿景，理清如何实现它的思路，并框定你的注意力。

*用个人品牌开启在线业务？*

**这就是你打造品牌的方式。**

你的愿景就是你帮助他人达成的理想结果。实现目标的路径就是你教导受众的内容。你的驱动力就是吸引志同道合之人的磁石。捕捉受众的注意力并框定他们的焦点，就是你帮助他们避开路障的方式。

额外奖励：用你喜欢的图片创建一个愿景板。我喜欢黑白的摩天大楼（我曾经梦想生活在大城市，而黑白恰好是我的风格），你能从我的品牌中看出来吗？

你想传达的*感觉*又是什么？你想传达怎样的环境、头像、色彩以及其他人类通过注意力来处理的信息形式？这关乎体验。

创造产品或服务也是同样的道理。理想的结果是什么？他们如何到达那里？你引导他们走过并获得结果的流程是什么？他们能够保持专注并真正取得那些结果吗？你有在为他们创造无缝体验吗？

下次当你在任何维度感到迷茫时——无论是思想、身体、灵魂、商业还是其他方面——请参考创造力金字塔来获得清晰度，并创造你想要生活在其中的现实。
