# 如何变得更加不随和(创造一个现实扭曲场)

<ArticleMeta />

在过去的一年里，我对自己有了很多了解。

尤其是，我意识到我这个人通常不太好相处。

我更喜欢独处。我讨厌脱离日常规律超过2-3天。我要么什么都不想，要么想得太多，中间地带很少。反复琢磨想法。为某个项目制定策略。反复思考某个问题。我一天的质量取决于我独处时间的质量，这可能会伤害到人际关系，因为我行为难以预测，会拒绝大多数外出邀请，随着时间推移，收到的邀请也就越来越少。

起初，我认为这是一种性格缺陷。

我想要改变它。

我们从小被教导要在任何情况下都保持友善，绝不露出锋芒。我们常常被告知要"稍微放开一点"，用别人的快乐方式取代自己的。我们害怕看起来像坏人，因为我们心中怀有一种妄想式的自我形象——那种高尚而善良的形象，但我们永远无法达到它。

当我过于友善时，我被人利用了。当我试图放松一点时，我的生活反而变得更糟。我感觉自己像是戴上了一副面具。我的注意力会分散，进展会放缓，那些曾带给我快乐的目标现在反而带来了痛苦。

经过一番思考，我意识到，**不好相处正是你走在正确道路上的标志。**

当我观察那些我敬仰的人时，他们的使命总是排在第一位。这正是让生活变得有意义的东西，而如果这种意义被剥夺，它会蔓延到他们的工作、他们所爱的人以及他们的友谊之中。

如果你清楚自己想要什么，并且不会屈服于别人认为你应该想要的东西，那你就会变得不好相处，**因为清楚自己想要什么的副产品就是变得不随和。**

事实上，你会发现人们反而更愿意接近你，因为他们信任你。

他们能感觉到，你没有像其他人那样在演戏。

### 过度随和的陷阱

高度随和的人厌恶冲突。

他们会不惜一切代价来平息事端。

而问题恰恰就发生在这里：**他们会牺牲自己的价值观、目标和愿景，只为避免伤害他人的感情**。大多数人之所以随和，是因为他们对某件事的在意程度还没有到不得不表现出不随和的地步。

他们同意每周末出去派对，这并不重要。

他们没有需要为之努力的重要目标，因此不会受到派对带来的精神能力下降的影响。他们的健康目标不受影响。他们的创造力也没有被用到，所以那也无所谓。感觉糟糕成了他们的默认状态，因为他们没有力气对享乐说不，因为拒绝会让朋友们开始施压，要求他们一起出去。

如果你对自己的薪水或在一段关系中受到的对待感到不满，你却会避免为自己站出来发声。

这样会发生三件事：

-   **问题会悄然累积成一种无法摆脱的弥漫性焦虑**，直到你进行那些艰难的对话为止
-   **别人的梦想会优先于你自己的**，让一切都显得空虚而暗淡
-   **你无法从生活中得到自己想要的东西**——你会带着遗憾死去

好消息是，你不需要变成一个刻薄的人才能扭转这一切。

### 如何变得更加不随和

![](/images/a7a38909dcf878c88976.webp)

高能动性的人是不随和的。

他们必须如此。因为如果他们想要朝着自己的目标行动，就必须首先不同意社会想把他们推上的默认路径，然后必须对试图把他们拉向不同方向的一切干扰说"不"。

史蒂夫·乔布斯(Steve Jobs)是出了名的不随和。

他有一个愿景，并且在实现它的过程中毫不妥协，这常常表现为他强烈的完美主义和残酷的坦诚。

现在，我们不需要在公司会议上把员工的工作成果叫做"垃圾"，也不需要毫无理由地把车停在残疾人车位上，**但我们确实需要一个现实扭曲场**：这是一个用来描述乔布斯说服自己和他人深信其愿景的能力的概念。

大多数人无法复制乔布斯的天才或个性，我们也要警惕明目张胆的操纵，但每个人都可以创造出一种让人无法抗拒的吸引力，从而帮助你更快地实现自己的愿景。

### 沉迷于你想要的东西

答案只会给予那些对问题痴迷的人。

解决方案只会给予那些对难题痴迷的人。

这就是你获取新知识的方式。

你与问题共处。与它较劲。考虑过放弃。到达崩溃的边缘。最终，它会屈服。一个小问题可能需要一周，一个人生难题可能需要十年，一个宇宙级的难题可能需要千年，但从来没有一个问题是无法解决的。

你人生中最重要的任务，就是弄清楚自己想要什么。

因为如果你不这样做(大多数人都属于这一类)，你就会在不知不觉中被操纵和利用。

一个不存在的目标是无法被分散注意力的。

如果你的学习没有目标，你什么都学不到。

人类是目标导向的生物。我们需要目的。我们朝之行动的东西塑造了我们是谁。当别人给我们分配那些处在默认路径上的目标时，我们不假思索地照做，我们慢慢变成了一个为自己没有选择的生活而努力工作的克隆体。

要弄清楚你想要什么，就要痴迷于它。

不应该有一天你不去想你想要的生活、你应该追求的目标、你应该采取的行动。这个简单的行为开始重塑你的思维。你开始注意到自己不想要什么，比如那份工作、财务上的不稳定、缺乏充实感。你的大脑开始进行纠错。你尝试新事物。慢慢地，你想要的东西的画面变得清晰起来。

不随和是清楚自己想要什么并且不在这一点上妥协的一个特征。

### 相信自己比大多数人更优秀

这可能让你感到不舒服。

但你需要相信，你可以比别人做得更好。

不是说你作为一个人某种程度上比他们更优越，而是说你可以创造出足够好一点点的东西，从而让你有机会去竞争。

现实是，大多数人创造的东西并没有那么好。世界上99%的人是消费者，只有1%是创作者。创作者并不是拥有什么你不知道的秘密的神奇存在。他们只是知道，要想得到自己想要的东西，就必须去创造，而他们不想要那种为自己毫不在意的东西效力、充当创造过程中的一个齿轮所带来的生活。

如果你不相信任何产品、文字、设计等等可以以某种重大或微小的方式变得更好，你就是在欺骗自己。再一次，是为了避免冲突。

**当你相信某件事可以被改进，并根据这个信念行动时，你就有潜力为这个世界贡献有价值的东西。**

如果你没有任何有价值的东西可以提供，没有人会在乎到愿意付钱给你、支持你，或加入你的事业。而上述这一切都是获得你想要的东西所必需的。

### 制定一个能拓展可能性边界的计划

你知道自己想要什么。

你有一些需要改进的东西——需要创造的东西——它会推动你朝那个方向前进。

现在，你需要一个计划，为你的思维以及那些你需要说服他们提供资源(时间、注意力、金钱、劳动、知识)以实现你愿景的人的思维，带来秩序和清晰。

但不能是随便什么计划。

**成功是衡量有多少人在乎你所做之事的一个指标。**投资者、朋友、员工、潜在客户不会在乎一个他们早已听过的无聊计划。

史蒂夫·乔布斯以要求在工程师最初认为不可能的时间框架内交付产品而闻名。

这样做有几个效果：

-   **提高进入心流状态的可能性**——当任务恰好处于不可能完成的边缘时，你会与这个任务融为一体，干扰会消失。
-   **迫使创造性思考**——当我的工作有一个4小时的截止时间时，几乎是神奇般地，我总能找到办法在这个时间内完成最高质量的工作。
-   **要求进行严格的优先级排序**——压力消除了考虑"锦上添花之物"的能力，迫使你专注于真正必要的东西。

这是一份变得不随和的秘方。如果你哪怕想一下要从自己的愿景中分心，一切都会崩溃，而由于你的愿景与你的身份认同交织在一起，你会不惜一切代价避免那种情况的发生(如果你确实对自己的愿景抱有坚定信念的话)。

### 精通有说服力的沟通

说服与操纵之间有着鲜明的区别。

-   **说服**：激励人们为双方都有益的事情而行动
-   **操纵**：误导人们为只对操纵者有益的事情而行动

如果你把注意力放在*任何*事物上，你同时既在被说服，也在被操纵。你的大部分信念和个性，都是别人的想法留在你脑中的结果。

除非你生活在真空之中，否则你既在说服别人，也在被别人说服。你不妨去研究一下它，从而有意识地追求互利。

如果你想得到你想要的东西，你无法独自达成。你需要投资者或员工。即使你不需要这些，因为你走的是一条"单人"的道路，你也需要受众、客户和资源。而想要掌控这些的唯一方法，就是精通有说服力的沟通。

要具有说服力，你需要两件东西：

-   **足够的研究来阐明你的论点**——这样你才能证明为什么你认为你的方式"更好"。
-   **一个能展现转变的引人入胜的故事**——大脑通过故事来理解世界，而故事能让人们在乎你所做的事情。

如果我们把一切串联起来，创造一个现实扭曲场：

你清楚自己人生中想要什么，并且不愿在这一点上妥协。

你相信某件事需要被改进。换句话说，你有一个问题要解决，而这个问题*会引向你想要的东西*。

你有一个清晰且战略上可实现的计划，能够到达你想要的地方。

在必要时，你能够激励他人帮助你的使命，从而消除那些可能阻碍你取得进展的潜在障碍。

现在，你不需要去创办下一个苹果公司才能变得不随和。

你只需要有一个让你无法自拔的有意义的目标，并拥有能够毫无干扰地朝这个目标行动的知识。

无论是你的健康、事业还是人际关系——你没能得到你想要的东西的根本原因，是因为你回避冲突，也没有营造出让那种冲突值得去解决的条件。
